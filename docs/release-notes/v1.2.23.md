## Tiếng Việt

Bản `v1.2.23` tiếp tục tăng độ tin cậy và quyền kiểm soát riêng tư cho **Ask this chat** (RAG), cải thiện điều hướng tới bằng chứng trích dẫn trên Android, và vá một lỗi vận hành nhỏ trong workflow giữ production Render luôn ấm.

### Điểm mới chính

- **RAG — an toàn và đúng ngữ cảnh hơn:**
  - Kiểm tra lại trạng thái đồng ý AI bên ngoài ngay trước khi gọi external embedding; khi người dùng thu hồi đồng ý, hệ thống chuyển về lexical embedding nội bộ thay vì tiếp tục gửi nội dung ra nhà cung cấp bên ngoài.
  - Câu hỏi không phải dạng truy vấn trực tiếp (ví dụ mệnh lệnh/khẳng định hẹp) chỉ được trả lời khi có bằng chứng truy xuất phù hợp; thiếu bằng chứng sẽ trả về `NOT_FOUND` thay vì suy diễn.
  - Benchmark âm tính đa ngôn ngữ được siết chặt để phát hiện hồi quy hallucination và trả lời không có bằng chứng.
  - Giới hạn công bằng số lượt sinh câu trả lời LLM đồng thời, có cấu hình concurrency/wait và metric riêng cho yêu cầu bị từ chối để tránh một đợt Ask làm cạn tài nguyên LLM.
- **Android — trích dẫn Ask sâu hơn:**
  - Nhảy tới tin nhắn được Ask trích dẫn theo `seq`, tải cửa sổ lịch sử xung quanh tin nhắn mục tiêu thay vì phải cuộn tuần tự qua toàn bộ hội thoại dài.
  - Dọn “jump island” tạm thời khi mở lại hội thoại để tránh giữ các đoạn lịch sử tách rời trong Room.
- **Vận hành:**
  - `keep-warm.yml` truyền `GH_REPO` cho các lệnh `gh issue`, tránh lỗi mở/đóng issue cảnh báo khi workflow chạy trong runner.

### Nâng cấp & cài đặt

- Không có migration database mới so với `v1.2.22`; server vẫn chạy trên schema Flyway `V48`.
- Tải `nexachat-v1.2.23.apk` (và `.aab` cho Play upload kèm checksum `.sha256`) từ [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.2.23) hoặc [trang tải về](https://nexachat.io.vn/download.html).

## English

`v1.2.23` further hardens **Ask this chat** (RAG) privacy and answerability, improves deep evidence navigation on Android, and fixes a small operations regression in the Render keep-warm workflow.

### Highlights

- **RAG privacy, grounding, and regression coverage:**
  - Re-checks external-AI consent immediately before external embedding calls; revoked consent falls back to internal lexical embeddings instead of sending content to an external provider.
  - Non-interrogative narrow prompts (for example imperative or declarative requests) now require retrieval evidence before answering; unsupported requests return `NOT_FOUND` rather than inferring an answer.
  - Multilingual negative benchmark coverage is tightened to catch hallucination and unsupported-answer regressions.
  - Concurrent LLM answer generation is fairly bounded with configurable concurrency/wait settings and a separate rejection metric so an Ask burst cannot exhaust LLM capacity.
- **Android deep Ask citations:**
  - Citation jumps use message `seq` to load a bounded history window around the cited evidence instead of forcing a linear scan through long conversations.
  - Temporary isolated history windows are cleaned when reopening a conversation, avoiding fragmented local Room history.
- **Operations:**
  - `keep-warm.yml` now passes `GH_REPO` to `gh issue` commands, keeping alert issue open/close automation reliable in GitHub Actions runners.

### Upgrade notes

- No new database migration beyond `v1.2.22`; the server remains on Flyway schema `V48`.
- Install `nexachat-v1.2.23.apk` (and verify `.sha256`) from [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.2.23); the signed Play bundle `.aab` is attached alongside the APK.
