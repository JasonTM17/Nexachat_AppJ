# NexaChat v1.2.2

## Tiếng Việt

### Giới thiệu
Bản `v1.2.2` chỉ thay đổi ứng dụng Android: các màn hình đăng nhập, đăng ký, hoàn tất hồ sơ, phương thức đăng nhập và xóa tài khoản được làm lại theo thiết kế Stitch. Máy chủ giữ nguyên `v1.2.1`; không có migration mới, không cần triển khai lại.

### Dành cho người dùng
- Đăng nhập và Đăng ký có thanh chuyển hai tab, ô nhập có biểu tượng, thẻ báo lỗi thống nhất.
- Nút "Tiếp tục với Google" dùng logo Google nhiều màu chuẩn; đường kẻ "hoặc" ẩn cùng nút khi Google không khả dụng.
- Hồ sơ → Phương thức đăng nhập: hàng Google có logo Google, hộp thoại mật khẩu có biểu tượng khóa.
- Xóa tài khoản chờ tải xong hồ sơ rồi mới chọn xóa bằng mật khẩu hay bằng mã email; nếu tải lỗi có nút Thử lại.
- Hủy cửa sổ chọn tài khoản Google khi liên kết không còn báo lỗi; thiếu Google Play services có thông báo riêng; thông báo tiếng Việt tự nhiên hơn.

### Vận hành
- Máy chủ giữ `v1.2.1` (commit `87be65ae`); không có Flyway migration mới, không có biến môi trường mới.
- Cấu hình OAuth: bản release dùng package `com.nexachat`, bản debug dùng `com.nexachat.debug`, mỗi bản có SHA-1 chữ ký riêng ([google-signin-setup](../google-signin-setup.md)).

### Giới hạn đã biết
- Tài khoản chỉ có Google chưa thể thêm số điện thoại hoặc đặt mật khẩu.
- Thông báo lỗi tên hiển thị theo từng trường chưa có.
- Đăng nhập Google thật trên điện thoại chưa được kiểm thử trên production tại thời điểm phát hành.

### Nâng cấp APK
- Hệ điều hành tối thiểu giữ nguyên: **Android 8.0 (API 26)** trở lên.
- Tải `nexachat-v1.2.2.apk` từ [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.2.2) và cài đè lên bản `v1.2.1`.

### Kiểm tra SHA-256
Mỗi bản phát hành đi kèm `nexachat-v1.2.2.apk.sha256`. So sánh mã băm tệp APK với chuỗi trong tệp checksum trước khi cài đặt (cùng lệnh như trong [`v1.1.1.md`](v1.1.1.md)).

## English

### Overview
`v1.2.2` changes the Android app only: the sign-in, register, complete-profile, sign-in-methods and delete-account screens are restyled to the Stitch design. The server stays at `v1.2.1`; no new migration and no redeploy needed.

### For users
- Sign in and Create account share a two-tab switch, fields with leading icons and a shared error card.
- "Continue with Google" uses the standard four-colour Google logo; the "or" divider hides together with the button when Google is unavailable.
- Profile → Sign-in methods: the Google row shows the Google logo and the password dialog has a lock icon.
- Delete account waits for the profile before choosing password or email-code deletion; a load failure shows Retry.
- Cancelling the Google chooser while linking no longer shows an error; missing Google Play services has its own message; Vietnamese wording reads more naturally.

### Operations
- The server stays at `v1.2.1` (commit `87be65ae`); no new Flyway migration and no new environment variable.
- OAuth setup: release builds use package `com.nexachat`, debug builds `com.nexachat.debug`, each with its own signing SHA-1 ([google-signin-setup](../google-signin-setup.md)).

### Known limitations
- A Google-only account cannot add a phone number or set a password yet.
- Field-specific display-name validation messages are not implemented.
- Real-device Google sign-in on production had not been exercised at release time.

### APK upgrade
- Minimum OS remains **Android 8.0 (API 26)** or higher.
- Download `nexachat-v1.2.2.apk` from [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.2.2) and install over `v1.2.1`.

### SHA-256 verification
Each release publishes `nexachat-v1.2.2.apk.sha256`. Compare the APK file hash to the checksum file before install (same commands as in [`v1.1.1.md`](v1.1.1.md)).
