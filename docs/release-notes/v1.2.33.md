# NexaChat v1.2.33

## Tiếng Việt

- Web Admin giữ phần đang nhập trong bản nháp thông báo Social và các công tắc
  chưa lưu khi xảy ra xung đột, kể cả khi bấm Thử lại nhiều lần mà tải vẫn lỗi.
- Khi tải lại thành công, các trường chưa sửa nhận giá trị mới từ máy chủ. Các
  nút ghi tạm khóa trong lúc tải và lần lưu tiếp theo dùng phiên bản cài đặt mới.

## English

- Web Admin keeps unsaved Social announcement fields and switch changes after
  a version conflict, even when several Retry attempts fail.
- Once the settings reload, untouched fields pick up the server values. Save
  and publish actions wait for the reload, then use the latest revision.
