# NexaChat v1.1.1

## Tiếng Việt

### Giới thiệu
Bản vá `v1.1.1` đi sau `v1.1.0`: sửa lỗi độ tin cậy trên máy chủ (triển khai Render), đồng bộ hóa delta khi ứng dụng kết nối lại sau mất mạng, và khôi phục cuộc gọi đến sau khi tiến trình Android bị hệ thống dừng.

### Thay đổi máy chủ
- Ghi số liệu Prometheus dùng khóa thẻ nhất quán giữa các chỉ số (`6da7a292`).
- Cấu hình Logback khai báo appender chỉ trong profile Spring đang bật, tránh cảnh báo khi khởi động (`1acc4135`).
- Ảnh runtime chứa kho lưu AppCDS; `render.yaml` ghi đè `JAVA_OPTS` của image để nạp `-XX:SharedArchiveFile=/app/application.jsa` (`fa6864e9`).
- Thư mục tạm multipart được tạo và kiểm tra ghi trước khi máy chủ nhận tải lên (`fff743ea`); hạn chế thời gian gọi S3 lấy từ cấu hình (`fbcacae5`).

### Thay đổi Android
- Đồng bộ delta chạy lại khi kết nối realtime được thiết lập lại, để tin nhắn bị lỡ trong các cuộc trò chuyện không đang mở xuất hiện sau khi có mạng (`09de3ccb`).
- Cuộc gọi đến vẫn mở được từ thông báo sau khi hệ thống kết thúc tiến trình ứng dụng (`cac1ddd3`).

### Tài liệu
- Hướng dẫn triển khai và vận hành cập nhật topology đã triển khai, scratch multipart và số đo JVM/AppCDS (`50e73120`, `ad063364`, `846e5431`, `d72396d6`, `fa85c8ec`, `b4729b67`).
- Mục giới hạn đã biết chỉnh theo cấu hình retention hiện tại (`cab7a54c`).

### Ghi chú vận hành
- Nếu bảng điều khiển Render ghi đè `JAVA_OPTS`, giữ cờ `-XX:SharedArchiveFile=/app/application.jsa` như trong [`render.yaml`](../../render.yaml) (dòng 45–55); nếu thiếu, JVM không nạp archive AppCDS được build trong image (`server/Dockerfile`, `fa6864e9`). Chi tiết: [`docs/production-runbook.md`](../production-runbook.md).
- Đặt `NEXACHAT_MULTIPART_TEMP_DIR=/app/data/multipart` trên dịch vụ sản xuất để phần multipart ghi ra đĩa bền thay vì thư mục tạm mặc định của container (`docs/operations.md`, `fff743ea`). Giá trị khuyến nghị ghi trong [`docs/operations.md`](../operations.md).

### Nâng cấp APK
- Yêu cầu hệ điều hành tối thiểu giữ nguyên: **Android 8.0 (API 26)** trở lên.
- Tải `nexachat-v1.1.1.apk` từ [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.1.1) hoặc [nexachat.io.vn/download.html](https://nexachat.io.vn/download.html) và cài đè lên bản `v1.1.0`.

### Kiểm tra SHA-256
Mỗi bản phát hành đi kèm `nexachat-v1.1.1.apk.sha256`. So sánh mã băm tệp APK với chuỗi trong tệp checksum trước khi cài đặt (cùng lệnh như trong [`docs/release-notes/v1.1.0.md`](v1.1.0.md)).

## English

### Overview
`v1.1.1` is a patch after `v1.1.0`: server reliability on Render, delta sync when the client reconnects after network loss, and restoration of incoming calls after Android process death.

### Server
- Prometheus meter registrations use consistent tag keys across metrics (`6da7a292`).
- Logback appenders are declared only inside the active Spring profiles, removing spurious warnings at startup (`1acc4135`).
- The runtime image bakes an AppCDS archive; `render.yaml` overrides image `JAVA_OPTS` to load `-XX:SharedArchiveFile=/app/application.jsa` (`fa6864e9`).
- The multipart scratch directory is created and write-probed before the server accepts uploads (`fff743ea`); S3 client deadlines are bound from configuration (`fbcacae5`).

### Android
- Delta sync runs again when the realtime connection is re-established, so messages missed while a conversation was not active appear after network recovery (`09de3ccb`).
- Incoming calls can still be opened from the notification after the system kills the app process (`cac1ddd3`).

### Documentation
- Deploy and operations guides record the live topology, multipart scratch path, and measured JVM/AppCDS footprint (`50e73120`, `ad063364`, `846e5431`, `d72396d6`, `fa85c8ec`, `b4729b67`).
- Known-limitations text matches the current retention configuration (`cab7a54c`).

### Operator notes
- If the Render dashboard overrides `JAVA_OPTS`, keep `-XX:SharedArchiveFile=/app/application.jsa` as in [`render.yaml`](../../render.yaml) (lines 45–55); without it the JVM does not load the AppCDS archive built into the image (`server/Dockerfile`, `fa6864e9`). See [`docs/production-runbook.md`](../production-runbook.md).
- Set `NEXACHAT_MULTIPART_TEMP_DIR=/app/data/multipart` in production so multipart parts land on durable disk instead of the container default temp directory (`docs/operations.md`, `fff743ea`). The recommended value is documented in [`docs/operations.md`](../operations.md).

### APK upgrade
- Minimum OS remains **Android 8.0 (API 26)** or higher.
- Download `nexachat-v1.1.1.apk` from [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.1.1) or [nexachat.io.vn/download.html](https://nexachat.io.vn/download.html) and install over `v1.1.0`.

### SHA-256 verification
Each release publishes `nexachat-v1.1.1.apk.sha256`. Compare the APK file hash to the checksum file before install (same commands as in [`docs/release-notes/v1.1.0.md`](v1.1.0.md)).
