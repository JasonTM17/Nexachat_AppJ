# NexaChat v1.2.35

## Tiếng Việt

- Màn hình lời mời Android chỉ hiện thẻ nhóm khi có thông tin nhóm. Lời nhắc
  đăng nhập dùng màu hướng dẫn của giao diện. Khi đăng nhập thành công,
  NexaChat tự quay lại đúng lời mời.

## English

- The Android invite screen displays the group card once group details are
  available. The sign-in prompt uses the standard guidance color. NexaChat
  returns to the same invitation after sign-in.
