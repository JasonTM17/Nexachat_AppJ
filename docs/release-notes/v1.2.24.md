## Tiếng Việt

Bản `v1.2.24` là một đợt nâng cấp chất lượng toàn diện cho **Ask this chat** (RAG) và **tóm tắt AI**: trả lời đúng bằng chứng hơn, citation chính xác và nhảy sâu hơn, minh bạch nguồn gốc tóm tắt, an toàn hơn khi thu hồi đồng ý AI — cùng một đợt remediation UX lớn trên Android, console quản trị và trang web công khai.

### Điểm mới chính

- **Ask this chat — đúng bằng chứng, rõ trạng thái (Server):**
  - Câu hỏi tra cứu ghép nhiều ý phải có đủ bằng chứng cho mọi thành phần cốt lõi; câu như “satellite deployment window” không còn bị trả lời từ một fact chỉ trùng một phần. Thiếu bằng chứng trả `NOT_FOUND` thay vì suy diễn, trong khi câu tổng hợp nhiều tin nhắn hợp lệ vẫn được trả lời đầy đủ.
  - Kết quả LLM được phân loại rõ (trả lời / từ chối có căn cứ / lỗi nhà cung cấp / quá tải bulkhead) với metadata bổ sung: lý do `NOT_FOUND`, lý do suy giảm, `retryable`, `retryAfterSeconds`, provenance và thông tin trích xuất.
  - Deadline end-to-end cho một lượt Ask (mặc định 110s, thấp hơn timeout Android 130s) — hết hạn trả về `TIMEOUT` có thể retry thay vì `NOT_FOUND` sai; race context sau chỉnh sửa/thu hồi được tính lại một lần hoặc báo `CONTEXT_CHANGED` thay vì `NOT_FOUND` giả.
  - Citation chính xác hơn: chỉ id được serialize mới trích được, phân vai PRIMARY/CONTEXT, snippet quanh truy vấn; bằng chứng deep-history được nạp theo cửa sổ seq giới hạn; câu trả lời extractive là span tối thiểu thay vì replay nguyên tin nhắn.
- **Tóm tắt AI — minh bạch và tôn trọng thu hồi đồng ý (Server + Android):**
  - Server kiểm tra lại quyền đồng ý AI ngay trước mỗi lượt gọi ra ngoài — kể cả retry 5xx, model dự phòng cloud và model local-server; thu hồi giữa chừng huỷ lượt gọi tiếp theo và không bị tính là lỗi nhà cung cấp.
  - Prompt tóm tắt được siết chất lượng: overview nêu rõ đã chốt/còn mở, key points không lặp, chỉ ghi decision khi có cam kết, action item khi có người được giao hoặc deadline, tiếng Việt tự nhiên hơn.
  - Android hiển thị một dòng provenance dưới tiêu đề tóm tắt: bản đã lưu, viết bằng model dự phòng, AI ngoài đang tắt/không trả lời, hoặc một số tin nhắn bị loại vì người gửi tắt AI — song ngữ EN/VI.
- **Android — remediation UX cho Ask và tóm tắt:**
  - Thread Ask không còn re-inflate mỗi lần gõ phím; thread được giữ lại khi đóng sheet trong phiên; snackbar tiến trình khi nhảy citation; citation ngoài cửa sổ nhảy được nhờ paging theo seq.
  - Chạm chip Local không còn thu hồi consent AI toàn tài khoản (preference theo sheet); lỗi lưu consent hiện snackbar; dialog consent có copy riêng cho Ask; checkbox action item giữ trạng thái khi rebind/xoay màn hình.
- **Console quản trị web (admin-web):**
  - Wave remediation operations: panel sức khoẻ RAG trên trang System (endpoint admin `GET /api/v1/admin/rag/stats` mới), deep-link `/admin/...` hoạt động khi refresh/share, nhãn tile 5xx đúng nghĩa, queue Alerts/Feed tự poll với refresh thủ công, focus-trap modal-stack đúng lớp, bảng mobile giữ cột quan trọng, xác nhận khi unhide/tạo rule, toast thành công, empty state theo ngữ cảnh.
  - Wave polish: icon điều hướng SVG thay glyph unicode, nút đổi theme dùng chung cho layout và trang đăng nhập, skip-link tới nội dung, mô tả ngắn từng trang, hiển thị tên operator cạnh role chip — song ngữ EN/VI.
- **Trang web công khai:**
  - Sửa chuyển ngôn ngữ trên các trang song ngữ (chỉ hiển thị một ngôn ngữ thay vì render đồng thời VI+EN); form xoá tài khoản web tách VI/EN độc lập.
  - Trang download dùng asset ổn định `nexachat-latest.apk` — release workflow copy và checksum asset này, có regression gate trong `site/check.py`.

### Nâng cấp & cài đặt

## English

`v1.2.24` is a broad quality release for **Ask this chat** (RAG) and **AI summaries**: stricter evidence grounding, precise deep citations, transparent summary provenance, safer consent revocation — plus a large UX remediation wave across Android, the admin console, and the public website.

### Highlights

- **Ask this chat — evidence-grounded, typed outcomes (Server):**
  - Multi-part compositional lookup questions require term evidence for every essential component; queries like “satellite deployment window” can no longer be answered from a one-sided fact. Missing evidence answers `NOT_FOUND` instead of inferring, while legitimate scoped multi-message synthesis still answers fully.
  - LLM outcomes are typed (answer / grounded abstention / provider error / bulkhead rejection) with additive metadata: `notFoundReason`, `degradationReason`, `retryable`, `retryAfterSeconds`, provenance, and extraction details.
  - End-to-end Ask deadline (default 110s, below Android's 130s timeout) — expiry returns a retryable `TIMEOUT` instead of a false `NOT_FOUND`; the post-edit/recall context race recomputes once or reports `CONTEXT_CHANGED` rather than a false `NOT_FOUND`.
  - Sharper citations: only serialized ids are citable, PRIMARY vs CONTEXT roles, query-centered snippets; deep-history evidence loads through bounded sequence windows; extractive answers are minimal spans instead of whole-message replays.
- **AI summaries — transparency and revocation safety (Server + Android):**
  - The server re-reads persisted AI consent immediately before every outbound call — including 5xx retries, the cloud fallback, and the local-server model; a mid-flight revocation cancels the next call and is not counted as a provider failure.
  - Sharper summary prompts: settled-vs-open overviews, non-repeating key points, decisions only on real commitments, action items only with an assignee or deadline, more natural Vietnamese.
  - Android shows a one-line provenance note under the summary header: saved copy, backup model, external AI off/unavailable, or messages omitted because their authors opted out — localized EN/VI.
- **Android — Ask & summary UX remediation:**
  - Ask threads no longer re-inflate on every keystroke and survive sheet dismissal within a session; progress snackbar while citation jumps load; out-of-window citations jump via seq-aware paging.
  - Tapping the Local chip no longer revokes account-wide AI consent (per-sheet engine preference); consent-save failures surface a snackbar; Ask has its own consent dialog copy; action-item checkbox state survives rebinds and rotation.
- **Admin web console:**
  - Operations remediation: RAG health panel on the System page (new admin `GET /api/v1/admin/rag/stats`), working `/admin/...` deep links on refresh/share, honest 5xx tile labels, polling Alerts/Feed queues with manual refresh, correct modal-stack focus trapping, mobile tables keep key columns, confirm-on-unhide and reasoned rule creation, success toasts, context-specific empty states.
  - Polish: SVG navigation icons replace unicode glyphs, a shared theme toggle across layout and login pages, skip-to-content link, per-page blurbs, operator display name beside the role chip — localized EN/VI.
- **Public website:**
  - Bilingual pages no longer render both languages at once; the web account-deletion form is split into independent VI/EN forms.
  - The download page uses the stable `nexachat-latest.apk` asset — the release workflow copies and checksums it, guarded by a regression gate in `site/check.py`.

### Upgrade notes

- No new database migration beyond `v1.2.23`; the server remains on Flyway schema `V48`.
- Install `nexachat-v1.2.24.apk` (and verify `.sha256`) from [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.2.24); the signed Play bundle `.aab` is attached alongside the APK.
