# NexaChat v1.1.2

## Tiếng Việt

### Giới thiệu
Bản vá `v1.1.2` đi sau `v1.1.1`: thay toàn bộ logo cũ bằng **Note mark** mới trên ứng dụng Android và trang web. Không có thay đổi bảng màu, kiểu chữ hay bố cục trong app.

### Android
- Biểu tượng launcher và monochrome adaptive icon dùng Note mark trên nền aubergine thương hiệu.
- Màn hình splash, đăng nhập và đăng ký hiển thị cùng một mark.
- Thông báo cuộc gọi dùng silhouette Note màu trắng (`ic_notification`).

### Trang web & kho media
- `favicon.svg`, `og-image.svg` và tài sản trong `docs/media/logo/` phản ánh Note mark.
- Giao diện trang tĩnh (`site/style.css`) điều chỉnh nút, liên kết và focus theo palette Note trên web.

### Nâng cấp APK
- Yêu cầu hệ điều hành tối thiểu giữ nguyên: **Android 8.0 (API 26)** trở lên.
- Tải `nexachat-v1.1.2.apk` từ [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.1.2) hoặc [nexachat.io.vn/download.html](https://nexachat.io.vn/download.html) và cài đè lên bản `v1.1.1`.

### Kiểm tra SHA-256
Mỗi bản phát hành đi kèm `nexachat-v1.1.2.apk.sha256`. So sánh mã băm tệp APK với chuỗi trong tệp checksum trước khi cài đặt (cùng lệnh như trong [`docs/release-notes/v1.1.1.md`](v1.1.1.md)).

## English

### Overview
`v1.1.2` is a patch after `v1.1.1`: the legacy logo is replaced everywhere by the **Note mark** on the Android app and the public website. There are no in-app palette, typography, or layout changes.

### Android
- Launcher and monochrome adaptive icons use the Note mark on the brand aubergine plate.
- Splash, sign-in, and sign-up screens show the same mark.
- Incoming-call notifications use a white Note silhouette (`ic_notification`).

### Website & repo media
- `favicon.svg`, `og-image.svg`, and assets under `docs/media/logo/` reflect the Note mark.
- Static site styling (`site/style.css`) aligns buttons, links, and focus with the Note palette on the web.

### APK upgrade
- Minimum OS remains **Android 8.0 (API 26)** or higher.
- Download `nexachat-v1.1.2.apk` from [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.1.2) or [nexachat.io.vn/download.html](https://nexachat.io.vn/download.html) and install over `v1.1.1`.

### SHA-256 verification
Each release publishes `nexachat-v1.1.2.apk.sha256`. Compare the APK file hash to the checksum file before install (same commands as in [`docs/release-notes/v1.1.1.md`](v1.1.1.md)).
