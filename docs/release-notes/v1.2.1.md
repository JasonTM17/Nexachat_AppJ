# NexaChat v1.2.1

## Tiếng Việt

### Giới thiệu
Bản `v1.2.1` là bản vá của `v1.2.0`: tài khoản chỉ có Google (không có mật khẩu) giờ có thể tự xóa tài khoản ngay trong ứng dụng bằng mã gửi tới email đã xác minh. Không có migration mới; máy chủ phải được triển khai **trước** khi người dùng cài APK mới.

### Dành cho người dùng
- Hồ sơ → Xóa tài khoản: với tài khoản chỉ có Google, ứng dụng gửi mã 6 chữ số tới email đã xác minh (hiệu lực 10 phút, 5 lần thử, dùng một lần), nhập mã để xác nhận xóa.
- Tài khoản có mật khẩu vẫn xóa bằng mật khẩu như trước.

### Vận hành máy chủ
- Endpoint mới `POST /api/v1/users/me/deletion-code` (đã xác thực, `202`; `409 PASSWORD_REQUIRED` nếu tài khoản có mật khẩu; `400 INVALID_OR_EXPIRED_CODE` nếu không có email đã xác minh). `DELETE /users/me` nhận thêm `code`.
- `GET /users/me` trả thêm `passwordSet`.
- Không có Flyway migration mới (vẫn V33). Không có biến môi trường mới.
- Giới hạn tốc độ riêng cho gửi mã xóa tài khoản (10/5 phút theo người dùng, 5/5 phút theo email, 30/5 phút theo IP).
- Render: auto-deploy tắt; deploy thủ công đúng commit ([deploy-render](../operations/deploy-render.md)).

### Giới hạn đã biết
- Tài khoản chỉ có Google chưa thể thêm số điện thoại hoặc đặt mật khẩu.
- Tóm tắt tin nhắn chưa bị xóa khi tin nhắn được thu hồi.

### Nâng cấp APK
- Hệ điều hành tối thiểu giữ nguyên: **Android 8.0 (API 26)** trở lên.
- Tải `nexachat-v1.2.1.apk` từ [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.2.1) và cài đè lên bản `v1.2.0`.

### Kiểm tra SHA-256
Mỗi bản phát hành đi kèm `nexachat-v1.2.1.apk.sha256`. So sánh mã băm tệp APK với chuỗi trong tệp checksum trước khi cài đặt (cùng lệnh như trong [`v1.1.1.md`](v1.1.1.md)).

## English

### Overview
`v1.2.1` is a patch on `v1.2.0`: a Google-only account (no password) can now delete itself in the app with a code sent to its verified email. No new migration; deploy the server **before** users install the new APK.

### For users
- Profile → Delete account: for a Google-only account the app sends a 6-digit code to the verified email (valid 10 minutes, 5 attempts, single use); enter it to confirm deletion.
- Accounts with a password still delete with the password as before.

### Server operators
- New endpoint `POST /api/v1/users/me/deletion-code` (authenticated, `202`; `409 PASSWORD_REQUIRED` when the account has a password; `400 INVALID_OR_EXPIRED_CODE` without a verified email). `DELETE /users/me` also accepts `code`.
- `GET /users/me` also returns `passwordSet`.
- No new Flyway migration (still V33) and no new environment variable.
- Dedicated rate limit for deletion-code requests (10/5 min per user, 5/5 min per email, 30/5 min per IP).
- Render: auto-deploy is off; deploy the exact commit manually ([deploy-render](../operations/deploy-render.md)).

### Known limitations
- A Google-only account cannot add a phone number or set a password yet.
- Message summaries are not purged when a message is recalled.

### APK upgrade
- Minimum OS remains **Android 8.0 (API 26)** or higher.
- Download `nexachat-v1.2.1.apk` from [GitHub Releases](https://github.com/JasonTM17/Nexachat_AppJ/releases/tag/v1.2.1) and install over `v1.2.0`.

### SHA-256 verification
Each release publishes `nexachat-v1.2.1.apk.sha256`. Compare the APK file hash to the checksum file before install (same commands as in [`v1.1.1.md`](v1.1.1.md)).
