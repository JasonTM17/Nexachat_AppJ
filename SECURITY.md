# Security Policy / Chính sách bảo mật

## Supported versions / Phiên bản được hỗ trợ

Only the latest release receives security fixes. The latest release in this
repository is `v1.2.7`; earlier releases are unsupported. / Chỉ bản phát hành
mới nhất được nhận bản vá bảo mật. Bản mới nhất trong kho mã này là `v1.2.7`;
các bản cũ hơn không còn được hỗ trợ.

| Version / Phiên bản | Support / Hỗ trợ |
|---|---|
| Latest release (`v1.2.7`) | Supported / Có hỗ trợ |
| Earlier releases / Các bản cũ hơn | Unsupported; upgrade to the latest release / Không hỗ trợ; hãy nâng cấp lên bản mới nhất |

## Report a vulnerability / Báo cáo lỗ hổng

Please report suspected vulnerabilities privately through GitHub's private
vulnerability reporting for
[`JasonTM17/Nexachat_AppJ`](https://github.com/JasonTM17/Nexachat_AppJ/security/advisories/new).
Do not publish vulnerability details in a public issue or discussion before
coordinating disclosure with the maintainers. / Vui lòng báo cáo riêng tư các
lỗ hổng nghi ngờ bằng tính năng báo cáo lỗ hổng riêng tư của GitHub cho
[`JasonTM17/Nexachat_AppJ`](https://github.com/JasonTM17/Nexachat_AppJ/security/advisories/new).
Không đăng chi tiết lỗ hổng trong issue hoặc thảo luận công khai trước khi
phối hợp công bố với người duy trì dự án.

Please include / Vui lòng cung cấp:

- The affected release or commit and the server or Android component involved. / Bản phát hành hoặc commit bị ảnh hưởng và thành phần server hoặc Android liên quan.
- A concise description of the security impact and conditions needed to trigger it. / Mô tả ngắn về ảnh hưởng bảo mật và điều kiện để tái hiện.
- Reproduction steps and a minimal proof of concept, when available. / Các bước tái hiện và bằng chứng khái niệm tối thiểu nếu có.
- Relevant configuration and logs with credentials, tokens, and personal data removed. / Cấu hình và nhật ký liên quan sau khi xóa thông tin xác thực, token và dữ liệu cá nhân.

Do not attach passwords, access tokens, signing keys, or real user content. / Không
đính kèm mật khẩu, access token, khóa ký ứng dụng hoặc nội dung thật của người
dùng.

## Response expectations / Kỳ vọng phản hồi

Maintainers intend to review private reports, acknowledge them when possible,
ask for clarification if needed, and share remediation or disclosure updates as
appropriate. Response time depends on the report and maintainer availability;
no acknowledgement, fix, or disclosure date is promised. / Người duy trì dự án
dự kiến xem xét các báo cáo riêng tư, xác nhận khi có thể, hỏi thêm thông tin
nếu cần và cập nhật việc khắc phục hoặc công bố khi phù hợp. Thời gian phản hồi
tùy thuộc vào báo cáo và khả năng của người duy trì; dự án không cam kết ngày
xác nhận, khắc phục hoặc công bố.
