Hướng dẫn cài đặt

  1. Tải tệp APK từ liên kết phát hành chính thức ở trên.
  2. Khi trình duyệt hoặc hệ thống hiển thị cảnh báo bảo mật, chọn cho phép cài đặt từ nguồn này.
  3. Mở tệp APK đã tải về và chọn Cài đặt để hoàn tất.

Kiểm tra tính toàn vẹn (SHA-256)

Mỗi bản phát hành đi kèm một tệp .sha256 chứa mã băm SHA-256 tương ứng của bản dựng APK. Bạn có thể kiểm tra trước khi cài đặt:

Trên Linux hoặc macOS:

sha256sum -c <tên-tệp>.apk.sha256

Trên Windows (PowerShell):

Get-FileHash <tên-tệp>.apk -Algorithm SHA256

So sánh mã băm thu được với giá trị được công bố trong tệp .sha256 trên trang phát hành GitHub Releases.

SHA-256 checksum verification

Each release provides a corresponding .sha256 file containing the cryptographic checksum of the APK. You can verify integrity before installing:

On Linux or macOS:

sha256sum -c <filename>.apk.sha256

On Windows (PowerShell):

Get-FileHash <filename>.apk -Algorithm SHA256

Compare the computed hash against the value published in the .sha256 release asset on GitHub Releases.
