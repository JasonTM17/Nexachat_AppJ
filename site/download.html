Kiểm tra tính toàn vẹn (SHA-256)

Mỗi bản phát hành có tệp nexachat-latest.apk.sha256 chứa mã băm SHA-256 của APK. Việc kiểm tra là tùy chọn nhưng nên thực hiện.

Trên chính điện thoại: tải và mở tệp .sha256, sao chép chuỗi 64 ký tự hex đầu tiên, rồi dùng một công cụ kiểm tra checksum đáng tin cậy trên điện thoại để tính SHA-256 của APK đã tải. Hai chuỗi phải khớp hoàn toàn; nếu khác, hãy xóa APK và tải lại từ trang này.

Nâng cao trên máy tính (tùy chọn): đặt APK và tệp .sha256 trong cùng một thư mục, rồi chạy lệnh phù hợp:

Trên Linux hoặc macOS:

sha256sum -c nexachat-latest.apk.sha256

Trên Windows (PowerShell):

Get-FileHash .\nexachat-latest.apk -Algorithm SHA256

Với Windows, so sánh giá trị Hash với chuỗi trong tệp .sha256 (không phân biệt chữ hoa/chữ thường).

SHA-256 checksum verification

Every release includes nexachat-latest.apk.sha256, which contains the APK's SHA-256 checksum. Verification is optional but recommended.

On the phone itself: download and open the small .sha256 file, copy the first 64 hexadecimal characters, then use a checksum utility you trust on the phone to calculate the downloaded APK's SHA-256. The two strings must match exactly; if they differ, delete the APK and download it again from this page.

Optional advanced desktop check: place the APK and the .sha256 file in the same directory, then run the appropriate command:

On Linux or macOS:

sha256sum -c nexachat-latest.apk.sha256

On Windows (PowerShell):

Get-FileHash .\nexachat-latest.apk -Algorithm SHA256

On Windows, compare the Hash value with the string in the .sha256 file (case does not matter).
